# Эмулятор UNIX-оболочки — вариант 19

Простой учебный эмулятор командной строки с графическим интерфейсом.
Программа написана только на Python и использует только стандартную
библиотеку.

## Возможности

- GUI с историей команд и строкой ввода.
- Заголовок вида `Эмулятор - [username@hostname]`.
- Раскрытие переменных окружения, например `$HOME`.
- Настройка через параметры командной строки.
- Выполнение стартового скрипта до первой ошибки.
- XML-журнал всех вызванных команд и ошибок.
- Загрузка виртуальной файловой системы из XML.
- Работа с VFS только в памяти без изменения исходного файла.
- Поддержка текстовых и двоичных файлов в base64.

## Команды

| Команда | Действие |
|---|---|
| `ls [путь]` | Показать файл или содержимое каталога |
| `cd [путь]` | Перейти в каталог, без пути — в `/` |
| `cat файл...` | Вывести файлы |
| `tac файл...` | Вывести строки файлов в обратном порядке |
| `chown владелец путь...` | Сменить владельца в памяти |
| `rmdir каталог...` | Удалить пустые каталоги в памяти |
| `exit` | Закрыть эмулятор |

`rmdir` не удаляет корень, непустой каталог и каталог, который содержит
текущую рабочую директорию.

## Запуск

Нужен Python 3.10 или новее. Установка пакетов не требуется.

```bash
./run.sh
```

Полный пример:

```bash
./run.sh \
  --vfs examples/vfs.xml \
  --prompt "student$ " \
  --log shell-log.xml \
  --startup examples/stage5.txt
```

Параметры:

- `--vfs` — путь к XML-файлу VFS;
- `--prompt` — приглашение к вводу;
- `--log` — путь к XML-журналу;
- `--startup` — путь к стартовому скрипту;
- `--headless` — выполнить скрипт без GUI, удобно для проверки.

При запуске значения всех параметров печатаются в терминал. Справка:

```bash
./run.sh --help
```

## Формат VFS

```xml
<filesystem name="demo">
  <directory name="/" owner="root">
    <file name="hello.txt" owner="student">Привет</file>
    <file name="data.bin" encoding="base64">AAECAwQ=</file>
    <directory name="empty" owner="student" />
  </directory>
</filesystem>
```

В `examples` лежат минимальная VFS, VFS с несколькими файлами и вариант с
тремя уровнями вложенности.

## Тестирование

Запуск всех модульных тестов и демонстрационных сценариев:

```bash
./scripts/test_all.sh
```

Отдельные проверки:

```bash
python3 -m unittest discover -s tests -v
./scripts/test_parameters.sh
./scripts/test_vfs.sh
./scripts/test_commands.sh
./scripts/test_mutating_commands.sh
```

Сценарии этапов 4 и 5 специально заканчиваются ошибкой. Обёртки проверяют,
что эмулятор остановился именно на ней. `test_mutating_commands.sh` также
сравнивает контрольную сумму XML до и после работы.

## Структура

```text
src/       исходный код
tests/     модульные тесты
examples/  XML-файлы VFS и стартовые сценарии
scripts/   сценарии проверки в реальной ОС
run.sh     основной скрипт запуска
```

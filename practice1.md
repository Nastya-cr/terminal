# Эмулятор командной оболочки UNIX

## Описание проекта

Проект представляет собой эмулятор командной оболочки UNIX-подобной операционной системы с графическим интерфейсом (GUI).

Разрабатывается в рамках дисциплины **«Конфигурационное управление»**, вариант №19.

Цель проекта — реализовать приложение, имитирующее работу командной строки UNIX, с поддержкой виртуальной файловой системы (VFS), выполнения команд, настройки параметров запуска и журналирования действий пользователя.

## Планируемая функциональность

- Графический интерфейс для взаимодействия с эмулятором.
- Интерактивный ввод и выполнение команд (REPL).
- Отображение имени пользователя и компьютера в заголовке окна.
- Поддержка раскрытия переменных окружения ОС (например, `$HOME`).
- Загрузка виртуальной файловой системы из XML-файла.
- Выполнение операций с VFS в оперативной памяти без изменения исходного файла.
- Настройка параметров приложения через аргументы командной строки.
- Выполнение команд из стартового скрипта.
- Логирование вызовов команд и ошибок в формате XML.
- Обработка ошибок ввода команд и загрузки файловой системы.

## Поддерживаемые команды

В ходе разработки планируется реализовать следующие команды:

| Команда | Назначение |
|---------|------------|
| `ls` | Просмотр содержимого директории |
| `cd` | Переход между директориями |
| `cat` | Вывод содержимого файла |
| `tac` | Вывод строк файла в обратном порядке |
| `chown` | Изменение владельца файла или директории |
| `rmdir` | Удаление директории |
| `exit` | Завершение работы эмулятора |

## Этапы разработки

### Этап 1. REPL
Создание минимального прототипа с графическим интерфейсом, парсером команд и базовой обработкой пользовательского ввода.

### Этап 2. Конфигурация
Добавление параметров запуска, пользовательского приглашения к вводу, стартовых скриптов и логирования событий в XML.

### Этап 3. Виртуальная файловая система
Реализация загрузки VFS из XML-файла и работы с её содержимым в оперативной памяти.

### Этап 4. Основные команды
Реализация полноценной логики команд `ls`, `cd`, `cat`, `tac`.

### Этап 5. Дополнительные команды
Реализация команд `chown` и `rmdir` для изменения состояния виртуальной файловой системы.
